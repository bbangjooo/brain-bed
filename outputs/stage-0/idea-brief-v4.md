# Brain Bed v4 - Idea Brief

> "명상하세요" 대신 "컨텍스트를 바꾸세요" — 마이크로 컨텍스트 스위칭 기반 휴식 앱

---

## 1. 컨셉 피벗 배경

### Reddit 커뮤니티 인사이트

Claude Code 사용자들의 피로 해소 패턴을 조사한 결과, **아무도 명상을 언급하지 않았다.** 실제 사람들이 하는 것:

| 패턴 | 예시 | 핵심 메커니즘 |
|------|------|-------------|
| **환경 전환** | 산책, 잔디 밟기, 샤워 | 컨텍스트 스위칭 |
| **감각 전환** | 종이책, 실제 세계로 나가기 | 디지털→아날로그 채널 변경 |
| **무의식 활용** | 수면, 샤워 중 아이디어 | 의식적 사고 끄기 (DMN 활성화) |
| **자기효능감 회복** | 수동 코딩으로 복귀 | AI 의존에서 벗어난 성취감 |

**핵심 발견**: 사람들은 "쉬는 것"이 아니라 **"다른 것을 하는 것"**으로 회복한다.

### v3 리서치의 과학적 근거

- **Active rest > Passive rest > No rest** (3시간 산술 과제 30명 대상 연구)
- DMN(Default Mode Network)은 **의식적 사고를 끌 때** 활성화 → 기억 통합, 창의적 사고
- 마이크로 브레이크는 **피로 감소 + 활력 증가 + 창의적 작업 성과 향상**
- 디지털 자연 노출도 실제 자연과 **유사한 인지적 이점** 제공 (ART 이론)
- 낙서/컬러링 같은 low-effort 창작이 **전두엽 피질을 강하게 활성화**하면서도 인지 부하는 낮음

## 2. 새로운 핵심 가치 제안

### Before (v1-v3)
> "컴퓨터를 끄지 않아도, 컴퓨터 안에서 **명상**할 수 있다."

### After (v4)
> "노트북을 덮지 않아도, 화면 안에서 **컨텍스트를 바꿀** 수 있다."

명상은 수동적이고 많은 사람이 거부감을 느낀다. 마이크로 컨텍스트 스위칭은:
- **능동적**: 무언가를 "한다" (그리기, 듣기, 움직이기)
- **다양한 선택지**: 기분에 따라 원하는 방식 선택
- **과학적**: Active Rest가 Passive Rest보다 효과적이라는 연구 결과
- **자연스러움**: 실제로 사람들이 이미 하는 행동 패턴을 디지털화

## 3. Inner Peace Zone → Context Switch Zone

기존 Inner Peace Zone을 **Context Switch Zone**으로 재설계한다.

### 3.1 컨텐츠 모드 (4가지)

```
휴식 진입 시:
├── 🎨 [Play]    인터랙티브 아트 — 감각 전환
├── 🌿 [Listen]  사운드스케이프 — 환경 전환
├── 🧘 [Move]    바디 무브먼트 — 신체 전환
└── 🎵 [Create]  크리에이티브 샌드박스 — 모드 전환
```

각 모드는 Reddit에서 발견한 4가지 회복 패턴에 1:1 매핑된다:

| 모드 | Reddit 패턴 | 과학적 근거 |
|------|------------|------------|
| **Play** (인터랙티브 아트) | 감각 전환 ("do something different") | 낮은 인지 부하 + flow state + DMN 활성화 |
| **Listen** (사운드스케이프) | 환경 전환 ("go for a walk", "nature") | ART 이론, 자연 소리가 스트레스 37% 감소 |
| **Move** (바디 무브먼트) | 무의식 활용 ("touch grass", "shower") | 스트레칭이 불편감 60% 감소, 생산성 10% 향상 |
| **Create** (크리에이티브) | 자기효능감 회복 ("manually coding") | 창작 활동이 코르티솔 유의하게 감소 |

### 3.2 각 모드 상세

#### 🎨 Play — 인터랙티브 제너레이티브 아트

마우스/트랙패드로 상호작용하는 시각 아트. 목적 없이, 판단 없이, 그냥 "놀기".

- **Particle Garden**: 마우스 움직임에 파티클이 피어남
- **Flow Field**: 유체 시뮬레이션, 색상 흐름 만들기
- **Sand Art**: 중력 기반 모래 시뮬레이션
- 기술: p5.js / Canvas API
- 인지 부하: ★☆☆☆☆ (매우 낮음)

#### 🌿 Listen — 자연 사운드스케이프

디지털 자연 환경으로의 컨텍스트 스위칭. 눈을 감거나, 창밖을 보거나.

- **Rain on Window**: 빗소리 + 창문 비주얼
- **Forest Ambience**: 새소리 + 바람 + 나뭇잎
- **Ocean Waves**: 파도 소리 + 해변 비주얼
- **Night Garden**: 귀뚜라미 + 밤하늘
- 기술: Web Audio API + 미니멀 비주얼
- 인지 부하: ★☆☆☆☆ (매우 낮음)

#### 🧘 Move — 바디 무브먼트 가이드

스크린에서 시선을 떼고 몸을 움직이게 만드는 가이드. "화면 밖"으로 유도.

- **20-20-20 Eye Care**: 20초간 20피트 거리 응시
- **Neck & Shoulder Release**: 3분 목/어깨 스트레칭
- **Hand & Wrist Care**: 손목/손가락 스트레칭
- **Stand & Breathe**: 일어서서 심호흡 3회
- 기술: 애니메이션 가이드 + 타이머
- 인지 부하: ★★☆☆☆ (낮음)

#### 🎵 Create — 크리에이티브 샌드박스

무언가를 "만드는" 행위를 통한 자기효능감 회복. 코딩과 완전히 다른 창작.

- **Tone Garden**: 클릭으로 음을 배치해 앰비언트 루프 생성
- **Pixel Canvas**: 16x16 픽셀 아트 그리기
- **Color Meditation**: 수채화처럼 번지는 디지털 페인팅
- 기술: Web Audio API + Canvas/p5.js
- 인지 부하: ★★☆☆☆ (낮음)

### 3.3 BFI 연동 자동 추천

BFI(Brain Fry Index) 레벨에 따라 추천 모드가 달라진다:

| BFI 레벨 | 추천 순서 | 이유 |
|----------|----------|------|
| 높음 (80-100) | Listen → Move → Play | 인지 부하 최소화 우선 |
| 중간 (50-79) | Play → Listen → Create | 적절한 engagement + 회복 |
| 낮음 (30-49) | Create → Play → Move | 능동적 활동으로 리프레시 |

사용자는 추천을 무시하고 원하는 모드를 자유롭게 선택 가능.

## 4. 명상의 위치 재정립

기존 명상/호흡 기능을 **제거하지 않는다.** Move 모드 안의 한 옵션으로 자연스럽게 포함:

```
🧘 Move
├── 20-20-20 Eye Care
├── Neck & Shoulder Release
├── Hand & Wrist Care
├── Stand & Breathe
└── Guided Breathing (기존 명상 기능)
```

명상을 원하는 사람은 여전히 쓸 수 있지만, 더 이상 **유일한 선택지가 아닌** 여러 옵션 중 하나.

## 5. UX 핵심 원칙

### 5.1 "3초 안에 시작"
- 모드 선택 → 즉시 시작. 설명/온보딩 없음.
- 이전에 선택한 모드를 기억해서 원클릭 재진입 가능.

### 5.2 "판단 없는 공간"
- 점수 없음, 진도 없음, 목표 없음.
- Play/Create 모드에서 만든 것은 저장하지 않음 (옵션으로 스크린샷 가능).
- "잘하고 있어요" 같은 메시지 없음. 그냥 공간만 제공.

### 5.3 "부드러운 전환"
- 진입: 작업 화면에서 천천히 페이드인 (0.5-1초)
- 종료: 갑자기 끊기지 않고 자연스럽게 페이드아웃
- 타이머 종료 30초 전에 부드러운 시각적 신호

### 5.4 "시간 유연성"
- 3분 / 5분 / 10분 / 15분 / 자유 시간
- 모든 모드가 어떤 시간이든 자연스럽게 동작

## 6. MVP 범위 (v4 Phase 1)

### 포함

| 항목 | 설명 |
|------|------|
| 모드 선택 UI | 4가지 모드 선택 화면 |
| Play: Particle Garden | p5.js 기반 인터랙티브 파티클 아트 1종 |
| Listen: Rain on Window | 빗소리 + 미니멀 비주얼 1종 |
| Move: Eye Care + Stretch | 20-20-20 + 기본 스트레칭 |
| Create: Color Meditation | 수채화 페인팅 1종 |
| BFI 기반 추천 | 피로도에 따른 모드 추천 표시 |
| 기존 기능 유지 | 타이머, 키보드 차단, 시스템 트레이 |

### 제외 (Phase 2)

- 추가 아트 모드 (Flow Field, Sand Art)
- 추가 사운드스케이프 (Forest, Ocean, Night)
- Tone Garden (크리에이티브 샌드박스 확장)
- 사용자 선호도 학습
- 퍼즐/미니게임

## 8. 기대 효과

1. **거부감 감소**: "명상? 난 안 해" → "오 이거 재밌는데?" 로 전환
2. **리텐션 향상**: 다양한 모드로 반복 사용 동기 부여
3. **타겟 확대**: 명상에 거부감 있는 개발자도 자연스럽게 유입
4. **차별화 강화**: 단순 타이머/차단 앱과의 차별점 극대화
5. **입소문**: "이 앱 휴식 모드가 진짜 좋음" → 유기적 성장
